# Zyra — Counselor Student Action Center

A small full-stack feature that helps a counselor quickly understand a student's
priorities, tasks, unread messages, and overall urgency level.

- **Backend:** Node.js · Express · TypeScript
- **Frontend:** React · TypeScript · Vite · Tailwind CSS · TanStack Query
- **Monorepo:** npm workspaces (`apps/backend`, `apps/frontend`)

> Setup, run instructions, API contract and the architecture note are filled in
> as the feature is built — see the sections below.

## Project layout

```
apps/
  backend/    Express + TypeScript API
  frontend/   React + Vite client
```
